# 参考スライド

参考URL: https://partner-prop.github.io/slides/mozumasu/terminal-night-3/1

2026-10-15に公開ページを確認。HTMLのメタデータから Slidev 53.0.0 製と分かる。タイトルは「zsh から学ぶ最高の UX」。Poppins、IBM Plex Sans JP、Fira Code を読み込み、16:9の固定キャンバス、強い見出し、赤のアクセント、表紙画像、OG画像を使用。GitHub Pages上の `/1` は404ページ経由でデッキに戻し、クライアント側で1枚目に移動する。

当サイトの `assets/theme-terminal.css` はこの資料の余白、配色、見出し帯、ページ番号、進行バー、セクション扉を参考にした共通テーマ。デスクトップは16:9、スマホは同じ要素を縦に再配置する。参考資料のブランド名と著作権表示は使わず、Slide Shareの表記に置き換える。
